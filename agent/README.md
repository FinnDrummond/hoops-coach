The Brick Detector voice agent (Node, LiveKit Agents + OpenAI Realtime, on FaceTime via Chert).
Overview, architecture and run steps are in the [root README](../README.md).

- `.env.example`: copy to `.env.local` and fill in your keys (never commit `.env.local`).
- `AGENTS.md` / `CLAUDE.md`: Chert's rules for coding agents. Leave as is.
